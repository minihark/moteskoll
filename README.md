## Overview
MötesKoll is a Swiss modernist real-time meeting odometer inspired by Braun and Dieter Rams. It tracks the exact SEK cost of meetings second-by-second with granular participant hourly rates, timebox countdowns, tactile Web Audio ticker ticks, and meeting summary exports.
